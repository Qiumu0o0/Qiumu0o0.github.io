## PSPACE

2026.10.07

First, I will introduce the definition of P, NP, SPACE and PSPACE.

For a function $f:\mathbb{N}\to\mathbb{N}$, $\mathrm{DTIME}(f(n))$ is the class of languages decidable by a deterministic Turing machine in $O(f(n))$ time, and $\mathrm{NTIME}(f(n))$ is defined analogously using a nondeterministic Turing machine.

$P=\bigcup_{k\geq 1}\mathrm{DTIME}(n^k)$ and $NP=\bigcup_{k\geq 1}\mathrm{NTIME}(n^k)$.

$\mathrm{SPACE}(f(n))$ is the class of languages decidable by a deterministic Turing machine using $O(f(n))$ tape cells, and $\mathrm{PSPACE}=\bigcup_{k\geq 1}\mathrm{SPACE}(n^k)$.

1. Prove $P \subseteq \mathrm{PSPACE}$.

If $L \in P$, then there exist a deterministic Turing machine $M$ and polynomial $p$, such that for every input $x$ $M$ halts within $O(p(|x|))$ steps, and accepts iff $x \in L$.

$L \in \mathrm{PSPACE} \iff \exists$ polynomial $p$, $L \in \mathrm{SPACE}(p(n))$. And each step visits at most one new tape cell, thus $M$ uses at most $p(n)$ cells. So for any $x$, $M(x)$ takes $O(p(|x|))$ cells during the running, and $x \in L$ iff $M$ accept $x$.

>From this question, I reviewed the def of P, also get a better understanding of SPACE and PSPACE. The most impoprtant understanding is that the Turing Machine always halt for any input.

2. Show PSPACE is closed under complement.

Assume $L$ in $\mathrm{PSPACE}$, we need prove that $\Sigma^* \setminus L$ in $\mathrm{PSPACE}$. Since $L$ in $\mathrm{PSPACE}$, then there exist an Turing Machine and a polynomial $p$, s.t. $M(x)$ halt within taking up $O(p(|x|))$ cells, and $x$ in $L$ iff $M(x) = \mathrm{Accept}$.

Then construct another Turing Machine $M'$:

for input $x$, run $M(x)$. If $M(x) = \mathrm{Accept}$, then Reject. else $M(x) = \mathrm{Reject}$, then Accept. So $M'$ is the Turing Machine for $\Sigma^* \setminus L$.

>This is a very usual construction that don't require any 'smart' lol.

3. Design a polynomial-space algorithm for TQBF.

>TQBF means True Quantified Boolean Formula. 

use **depth-first recursion**:

>depth-first recursion: try all possibility for one var each time.

Input tape (not counted):

```text
∀x ∃y (x∨y)
```

Work tape during one branch:

```text
| x=0 | y=1 | level=2 | result=T |
```

After returning:

```text
| x=1 | y=_ | level=1 | result=_ |
```

Old branches are erased and reused. At most $O(n)$ assignments occupy cells.
