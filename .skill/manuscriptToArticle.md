2. for every literature, using the original english version. If some information cannot tell in the manuscript, you can search the Internet to complete the information, and also attach them by links.
3. For every picture of automata, draw the picture like this: tutorial\public\opacity-cso-automaton.svg and cite it in the corresponding place.
4. The picture pdf may contains some new information, new pages, but except for there was something missing in the previous blog article, do not edit the previous notes unless I command you to do that.
